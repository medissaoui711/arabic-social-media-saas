# Arabic Social Media Management SaaS

Arabic-first, responsive RTL web SaaS for managing social media content through a secure workspace-based experience.

## Product direction

- Modular Monolith with a shared backend/API.
- API versioning under `/api/v1`.
- Workspace-scoped authorization and strict tenant isolation.
- P1 includes authentication foundations, workspaces and memberships, content lifecycle, secure media, internal calendar/scheduling, internal social-account metadata, audit, and operational reliability.
- P1 excludes external social publishing, social OAuth/API integrations, external analytics synchronization, billing/subscriptions, public registration, and native mobile applications.
